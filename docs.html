TurtleNES Documentation (v1.1)

TurtleNES

A Nintendo Entertainment System emulator written from scratch in JavaScript. It runs entirely in your browser. Your ROM files never leave your computer.

Quick start

  1. Choose File > Open ROM... (or press Ctrl+O), or drag a .nes file onto the window.
  2. Play with the keyboard. The default keys are listed below.
  3. Press F5 to save a state and F7 to load it again. This is instant and does not open any dialog.
  4. Use Tools > Debugger to inspect the emulated hardware.

TurtleNES does not include any commercial games. You need to supply your own ROM files.

Open Input > Configure Controller 1 or Controller 2. The window lists the keys that are actually bound right now. Click Change next to a button and press the new key. The new binding is used by the game immediately. Choosing a key that another button uses moves it to the new button. F-keys, Escape and Backspace are reserved for emulator shortcuts. Defaults restores the original keys for the selected controller. Bindings are remembered by your browser.

Input display

Turn on Input > Input Display (or the Pads toolbar button) to show both controllers. Each button lights up while it is pressed, and shows the key that is currently bound to it.

Save states

Save State (F5) and Load State (F7) use one quick slot per game. They are instant and never open a file picker. A message in the status bar and on the screen tells you what happened, and the status bar shows when the slot was last written. Saving again replaces the slot ("State overwritten"). Delete Save State empties it. The slot is remembered by your browser between visits.

Export Save State... downloads the saved state as a .tnesstate file (or the current state if the slot is empty). Import Save State... loads such a file, or you can drop it on the window. The file contains the CPU, memory, PPU, sound chip, cartridge mapper and controller state, and the identity of the ROM. A state made for a different ROM is refused with an error message. Importing does not touch the quick slot.

Battery-backed game saves (the ones games make themselves) are separate. They are kept automatically per game, and Clear Cartridge Save Data removes them.

Rewind

While a game runs, TurtleNES keeps a short history of snapshots. Hold Backspace (or the Rewind toolbar button) to run time backwards, and release to continue from that point. Emulation > Rewind... lets you turn recording off, choose the history length (10 to 120 seconds), and drag a timeline to jump to any moment. The history is limited in size, and the window shows how much memory it uses.

Speed

Emulation > Speed offers 0.5x, 1x, 2x, 4x and a custom value from 0.1x to 10x. The emulator really runs more or fewer frames per second. Sound is switched off whenever the speed is not 1x, because sped-up audio is not useful. Very high speeds depend on how fast your computer is; the status bar shows the real frame rate.

Cheats

Emulation > Cheats... holds a list of RAM cheats for the current game. Each cheat can be switched on and off or removed. Cheats are remembered per game, are separate from save states, and never change the ROM.

AAAA:VV        write hex value VV to address AAAA every frame
AAAA:VV?CC     same, but only while the byte at AAAA equals CC

Example: 0075:09 keeps the byte at address $0075 at 9. Addresses must be in work RAM ($0000 to $1FFF) or cartridge RAM ($6000 to $7FFF). Game Genie and Pro Action Replay codes are not supported.

Video: scale, filters and fullscreen

Video > Scale picks the window size. Video > Filter has four choices:

Fullscreen (F11) uses the mode chosen in Video > Fullscreen Mode. The picture is always centred on a black background.

NormalThe current window scale, centred (reduced only if the screen is too small)
SquareThe largest whole-number multiple of 256x240 that fits, so every pixel is the same size
Keep Aspect RatioAs large as possible without distortion, with black bars where needed
Fill ScreenStretches to the whole screen (this distorts the picture)

Open Recent

File > Open Recent lists the last ROMs you opened with their mapper and when you opened them. In browsers that let a page keep permission for a file (such as Chrome and Edge), choosing an entry reopens the file, possibly after asking for permission. In other browsers, or if access was lost, TurtleNES tells you so and asks you to select the file again. Only the file name and details are stored, never the ROM data.

CPU compatibility: undocumented opcodes

The 6502 processor responds to many opcodes that its manufacturer never documented, such as LAX, SAX, DCP, ISC, SLO, RLA, SRE, RRA, ANC, ALR, ARR and AXS, plus extra NOP forms. Some games and test programs use them. They are off by default. Turn them on under Emulation > CPU Compatibility.... With them off, executing one halts the CPU, as in earlier versions. Turning them on changes nothing for programs that only use official opcodes.

Limitations

  • Not every NES game works. Compatibility is limited to the mappers above and the accuracy of the PPU and APU.
  • Mid-scanline PPU tricks that need exact PPU bus timing may glitch.
  • The sprite overflow flag does not reproduce the real chip's hardware bug.
  • Sound quality is a straightforward mix of the five channels without hardware filtering.
