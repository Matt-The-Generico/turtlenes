    About TurtleNES
    X
  

  

    
    

      
TurtleNES v1.1

      
A Nintendo Entertainment System emulator, written from scratch in JavaScript.

      
No external emulator cores were used. The 6502 CPU, PPU, APU, and mappers are all implemented directly in this project.

      
This program does not include or distribute any commercial ROM files. Please use your own legally obtained ROM dumps.

      Instruction set
      
      
    

    
Undocumented opcodes are side effects of the 6502 design that the manufacturer never documented (LAX, SAX, DCP, ISC, SLO, RLA, SRE, RRA and others). A few games and test programs use them. Leave this on "Official opcodes only" unless a game needs the extras. With official-only mode, running an undocumented opcode halts the CPU.

    Cheats
    X
  

  

    

    
Code:  Name: 
      

    

    
Format: AAAA:VV writes hex value VV to address AAAA every frame. AAAA:VV?CC only writes while the byte currently equals CC. Addresses must be in work RAM ($0000-$1FFF) or cartridge RAM ($6000-$7FFF). Cheats never change the ROM and are not part of save states.
